# Privacy / 隐私说明

GlyphOrder / 字序 processes fonts and settings locally on your Android device.

- The application declares no Internet permission. It contains no analytics, advertising SDK, account system or telemetry upload.
- Fonts selected through Android's document picker are copied into app-private storage. Settings, font metadata, previews, generated modules and installation backups stay on the device.
- Root access is used to inspect system font configurations and metadata, install or disable the GlyphOrder Magisk module, and reboot only after an explicit user action. It is not required to read these legal pages.
- Export writes the module to the destination you choose through Android's document picker. That destination may be a cloud provider you have installed; the provider's own privacy policy applies.
- Opening the source repository launches your browser. GitHub and your browser handle that external visit under their own policies.
- Android application backup is disabled. Clearing application storage or uninstalling removes app-private data. Exported files and installed Magisk modules are managed separately; disable the module and reboot before uninstalling if you want to restore system fonts.
- Reports you choose to post publicly can contain ROM fingerprints, font names or system configuration. Review a report before sharing it.

This statement describes GlyphOrder, not Android, Magisk, your ROM, document providers or other applications. There is no developer server receiving application data.
